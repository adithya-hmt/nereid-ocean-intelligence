# Nereid data snapshots

`snapshots/` is ignored except for the small committed `indian-ocean-2023-03`
real GDAC replay snapshot. Other locally prepared ARGO source files and normalized
Parquet outputs remain ignored. Prepare a snapshot only from an explicitly selected,
cited GDAC source:

```bash
nereid-prepare --netcdf FILE --output data/snapshots/indian-ocean-2023-03 --source-url URL --snapshot-doi DOI
```

The command records the source URL, snapshot DOI, fetch timestamp, and SHA-256 in
`manifest.jsonl`. The normalized files preserve raw and adjusted observations and
QC flags; downstream scientific outputs must exclude QC 3 and 4.

The committed replay snapshot contains official delayed-mode GDAC profiles WMO
1902202/cycle 161 and WMO 2902388/cycle 274, with raw NetCDF, immutable source
checksums, fetch timestamps, DOI citation, raw/adjusted observations, and QC.
The latter preserves both source vertical sampling representations via
`source_profile_index`; it is never silently merged.

The NetCDF fixture generated by `pipeline/tests` is synthetic, labeled test-only,
and must never be used as a scientific output or snapshot.
